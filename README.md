# 🚀 Dynamic Quiz Application with Selenium Automation

## 📌 Project Overview
The **Dynamic Quiz Application** is a web-based quiz system developed using **PHP, HTML, CSS, and JavaScript**.  
It allows users to attempt quizzes with a countdown timer, dynamic question loading, and detailed result analysis.  
The complete quiz flow is automated using **Selenium WebDriver (Java)** to validate functionality and performance.

---

## 🎯 Objectives
- Build a dynamic quiz application without using any backend database
- Implement a countdown timer for each question
- Display detailed result analysis after quiz completion
- Automate end-to-end quiz interaction using Selenium WebDriver

---

## 🛠️ Technologies Used

### 🔹 Frontend & Logic
- HTML5  
- CSS3 (Responsive UI)  
- JavaScript (Dynamic questions, timer, score calculation)

### 🔹 Backend (Lightweight)
- PHP (Page navigation only, no database)

### 🔹 Automation Testing
- Java  
- Selenium WebDriver  
- Chrome Browser  
- Visual Studio Code  

### 🔹 Server
- XAMPP (Apache)

---

## ✨ Application Features

### ✅ Quiz Features
- Category selection (General, Math, Logic)
- Difficulty levels (Easy, Medium, Hard)
- One question displayed at a time
- Countdown timer for each question
- Automatic submission when timer expires
- Final result analysis with:
  - Correct answers
  - Incorrect answers
  - Total score
  - Performance summary

### ✅ Automation Features
- Automatic browser launch
- Quiz start button click
- Answer selection for all questions
- Quiz submission
- Result page validation
